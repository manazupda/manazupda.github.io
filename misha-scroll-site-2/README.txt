Как запустить
1. Положите index.html и scroll.mp4 в одну папку.
2. Откройте через локальный сервер (не двойным кликом, иначе Chrome может плохо перематывать видео):
     python3 -m http.server 8000
   и зайдите на http://localhost:8000
3. Для публикации загрузите обе файла на любой хостинг (Netlify, GitHub Pages, Vercel и т.д.).

Настройка
- Скорость: переменная --scroll-length в начале CSS (900vh). Больше = медленнее.
- Плавность: SMOOTHING в JS.
- Тексты на экране: массив SCENES (секунды видео, подпись главы, заголовок).
